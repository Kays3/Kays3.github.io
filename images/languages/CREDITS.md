# Language bird icons

All four icons are PhyloPic silhouettes dedicated to the public domain under CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/. Downloaded 25 October 2026. Used as language navigation symbols, not national emblems.

* English: mute swan (Cygnus olor), Andy Wilson, https://www.phylopic.org/images/95f4447f-2ef4-4061-ad9f-3de17e71afeb
* Japanese: red-crowned crane (Grus japonensis), Kai Caspar, https://www.phylopic.org/images/82b7a983-7e1c-4c4a-b1d6-307e00e75fa1
* Russian: common pheasant (Phasianus colchicus), Mattia Menchetti, https://www.phylopic.org/images/8b720ff5-8e5a-4640-babc-cc30d6495a84/phasianus-colchicus
* Kazakh: golden eagle (Aquila chrysaetos), Anthony Caravaggi, https://www.phylopic.org/images/b2b60a18-fd7d-49b2-a15d-54a62cdcac6b

Original SVG artwork retained. Display sizes and dark mode inversion are applied by CSS. Language names remain available as accessible link names and tooltips.
