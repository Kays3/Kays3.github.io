# About banner prompt

Generated 2026-09-30 with the built-in image generation tool for the site's About-page hero.

The artwork was regenerated from the existing cellular research banner as a visual reference. The prompt requested a panoramic scientific illustration featuring *Helicobacter pylori* near gastric epithelial tissue, active T cells, molecular and DNA signals, and a restrained Okinawa setting with turquoise sea, green island vegetation, and volcanic coastline silhouettes. The center was kept dark and uncluttered for the page title. The result is decorative artwork and does not depict measured data or a literal experiment.
